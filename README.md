# 星枢 · 更新包

这个仓库**只放更新包**，不含任何项目源码。

## 我要安装 / 更新星枢

点右边（或上面）的 **Releases**，下载最新安装程序 `星枢安装器.exe`，双击安装即可。

- **已经装过星枢**：安装程序会装回原来的位置，并且**保留你已经装好的模块**和登录状态。
- **全新安装**：装完首次打开，需要输入运营方给你的账号和密码。

## 我拿到了模块包（.zip）

在星枢客户端里点「导入模块…」，或者把 zip 直接**拖进窗口**（一次可以拖多个）。
装之前会弹一个确认框，上面写着这个模块要什么权限，确认了才开始装。
